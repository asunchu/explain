# Pele dependency update

On October 25, 2026, the Explain diagram renderer moves from Pele 1.6.0 to 1.10.0.
The package and lockfile pin the exact release.

## Verification

- All 13 existing renderer tests pass.
- The production dependency audit reports no known vulnerabilities.
- npm verifies the package registry signature and provenance attestation.
- The upstream release notes and security guidance were reviewed.

The wrapper still disables links and images and supplies no icon or math callback.
Source, edge, output, dimension, and worker deadline limits remain unchanged.
Tests cover these limits, escaped labels, accessible output, narrow layouts, and protected output files.

This is a dependency regression check, not a repeat of the full October 18 security review.
The older review describes Pele 1.6.0 only.
Existing published media and example exports are unchanged.

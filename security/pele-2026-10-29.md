# Pele 1.12.0 dependency check

On October 29, 2026, the repository renderer moves from Pele 1.10.0 to 1.12.0.
The package manifest and lockfile pin the exact version.

## Checks

- All 15 renderer tests pass with 1.12.0, including two new checks for contrast and group opacity.
- All three PNG export protection tests pass.
- npm reports no known vulnerabilities in the production dependency audit.
- npm verifies the registry signature and provenance attestation for Pele.
- Sixteen SVG variants render through the existing worker wrapper.

The wrapper retains its source, edge, output, dimension, and deadline limits.
It still disables links and images. No custom icon or math callback is added.
The interactive demonstration selects pre-rendered assets. It does not accept untrusted source or insert generated SVG through `innerHTML`.

This is a dependency regression check, not a complete security audit.
The October 18 review describes the older package version and must not be treated as a review of 1.12.0.
No claim of immunity to unknown vulnerabilities is made.

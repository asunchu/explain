# Plain word guide

This is an original house word guide. It is not the ASD-STE100 approved dictionary.
Use the suggested word only when it preserves the intended meaning.
Do not run these substitutions blindly over a file.

| Avoid in editable prose | Prefer | Meaning or limit |
| --- | --- | --- |
| utilize | use | Use a tool or resource. |
| commence | start | Start a task. |
| terminate | stop or end | Preserve a technical name such as SIGTERM. |
| facilitate | help or make easier | State what becomes easier. |
| leverage | use | Preserve the term in a financial explanation. |
| aforementioned | named earlier | Repeat the exact item name when clearer. |
| subsequent | next or later | Keep the order precise. |
| prior to | before | Use for order or time. |
| in order to | to | State the purpose directly. |
| due to the fact that | because | Give the cause. |
| at this point in time | now | Use only for the present. |
| in the event that | if | Keep the condition. |
| ascertain | check or find | Choose based on the action. |
| endeavor | try | Do not turn an attempt into a result. |
| perform a check of | check | Keep the object of the check. |
| make a selection | select | Name the item. |
| carry out an installation of | install | Name what to install. |
| is required to | must | Keep the actor. |
| is capable of | can | Preserve capability rather than certainty. |
| a number of | several or an exact count | Use a known count when useful. |
| functionality | function or behavior | State what the software does. |
| optimal | best for a named goal | Do not imply a measured optimum without evidence. |
| seamless | describe the actual behavior | Do not promise that failures cannot occur. |
| robust | describe the tested condition | Give evidence instead of a vague claim. |

Use stable verbs such as start, stop, remove, install, set, and check.
Use “make sure” when the reader must establish a condition before an action.
Choose one name for each object. Keep that name through the text, diagram, and script.
Define technical terms that the reader needs. Keep exact API names, commands, paths, product names, and quoted errors.

For a word outside this guide, choose a common word with one clear meaning in context.
Do not call that word “approved by ASD-STE100” without checking the official dictionary.
In strict formal work, check the word's meaning, part of speech, and permitted forms against the official source.

One skill. Different ways to learn.

A definition may need three sentences. A system may need a diagram. Choices become an interactive walkthrough. A story unfolds in a film. Explain honors the format you request and otherwise chooses the smallest one that helps.

Install across your agents

npx skills add asunchu/explain --skill explain -g   -a codex -a claude-code -a opencode

Requires Node.js/npm for installation. Rendering tools are installed only when needed. Usage and compatibility →
